TrynDraft is my League of Legends drafting tool, planning and implementing with
production and release online via docker in mind. A full stack application, goal
is for the app to allow the user to pick all draft states picks and bans on an
orderly neat way, and the app gives suggestions and explanations on each pick at
ecery stage in the draft. I am looking for two main parts in the logic: a neural
net composed of information about champ statictics etc, and a LLM agent that is 
finetuned on textual data that gives explantions and logic in a textbox that is 
integrated into the frontend. This project is meant to be released on the 
internt and be viable for production, so always keep that in mind when working
on it and don't do stuff that will be local or placeholder stuff. If you need 
to get all the champions, don't create an in place list and be lazy, but call an
api to get all the current champs. If you suggest changes/deletions/new files,
you HAVE to explain why. You can't just tell me what to do if you don't explain
the issue and why you are doing what you are doing.
